# 💬 Website Discussions

Welcome to the discussion repo for **aleksandarpopovic.com**!  
This repo powers the comments and feedback system on my upcoming website using **[Giscus](https://giscus.app/)**.

---

## ✅ What is this for?
Giscus uses **GitHub Discussions** as a commenting system. When you leave a comment on my site, it creates a discussion in this repository.

---

## ⚠️ Disclaimer
This feature is for a **new website currently in development**.  
Any comments posted here **won't appear on the site until it goes live**.

---

## ✨ How to Participate
1. **Sign in with GitHub** on the website (once live).
2. Leave a comment, feedback, or suggestion.
3. Your comment will appear here as a discussion!

💡 *Bonus: Your comment might even make it to the highlights section!* 🎉

---

## 🔒 Notes
- All comments are public.
- Be respectful and follow [GitHub's Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines).
